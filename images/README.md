# 圖片替換手冊

這份文件說明**網站上每一張圖片要放哪裡、要什麼比例、換掉之後怎麼生效**。

目前除了兩張設計師頭像，所有位置都放了**範例圖**（左上角有 `範例圖 SAMPLE` 角標）。
那些不是產品照，用同檔名覆蓋就會換成你的照片。設計師頭像刻意沒放範例圖——那是真實人物，
不該用生成的臉冒充。

---

## ⚡ 一分鐘版

1. 把你的照片改成下表的**檔名**（大小寫要一致，副檔名一律 `.jpg`）
2. 丟進 `images/` 資料夾，**覆蓋**原本的範例圖
3. 重新整理網頁就會看到

⚠️ **第 3 步只讓你自己電腦上的檔案生效，線上網站還是舊的。**
要讓真正的網站更新，還要上傳到 GitHub——做法見
[../README.md 的「🚀 更新網站」章節](../README.md#-更新網站自己改完之後怎麼上線)。

不需要改任何程式碼。唯一需要動程式的是**介紹影片的連結**（見下方「介紹影片」）。

## 📸 各區的特別規則

### 首頁：淡色版與原色版必須「同角度」

滑桿的意義是「同一個東西的兩種顏色」。如果兩張的角度或距離不同，拖曳時會看起來像
**換了一張圖**，而不是顏色在變。

> **實務做法：腳架不要動。**
> 同一個位置先拍第二代（原色），換上第一代（淡色）再拍一張，中間不要移動相機。
> 背景、光線、構圖都保持一致。

**只做一組也可以。** 三張是各自獨立的：

1. 三張都先放原色版
2. 挑**一個**最好拍的場景，腳架不動補拍淡色版
3. 只放那一張的 `-pale.jpg`

沒有淡色版的那張，滑桿會自動隱藏，只顯示原色版，不會破圖。

兩色的交界是一條約 76px 的漸層帶，不是硬邊，所以兩張照片不需要對到像素級。
分隔線**左邊是第一代（Gen1）、右邊是第二代（Gen2）**，預設停在 38%（第二代佔畫面 62%）。

### 多功模式：兩套圖不要互相替代

| | 大預覽 | 小卡縮圖 |
|---|---|---|
| 檔名 | `mode-{key}.jpg` | `mode-{key}-thumb.jpg` |
| 程式怎麼放 | `cover`（填滿；16:9 與框同比例所以不裁切） | `contain`（完整顯示，不裁切） |
| 適合的照片 | 情境照 | 白底商品照 |

`{key}` 是 `art` / `chair` / `shelf` / `table` / `console`。

**只準備一套也可以：** 缺 `-thumb.jpg` 時，小卡會自動改用同模式的大預覽圖並切成 `cover`。
所以最省事的做法是先只準備 5 張情境照，之後想要白底商品照再補。

白底商品照建議 **3:2**——縮圖框也是 3:2，比例一致就不會出現上下白邊條。
產品置中、四周留一點空間即可，程式不會裁切。

### 世代與規格：4:3 橫式

這兩張 2026-08-18 從 1:1 改成 **4:3**，因為展覽現場照通常是橫式（相機預設就是 4:3），
放進 1:1 的框會被裁掉左右各 12.5%（共四分之一的寬度），現場的空間感就沒了。

直接放 4:3 原圖即可，不用先裁。程式用 `cover` 填滿，所以只要來源是 4:3 就不會裁到東西。

> 滑鼠移到圖片上（手機是點一下）會浮出 4 項規格（3 項兩代差異＋作品尺寸）。
> 那個浮層蓋在圖片上，所以**產品盡量不要頂到畫面正中央偏上的位置**，
> 不然浮出來時會擋住主體。

### 設計理念：右圖固定 1:1

這張在所有螢幕寬度都是正方形。程式用 `cover` 裁切，所以**準備方形照片最保險**；
如果來源不是方形，請把重點放在畫面中央。

## 🎬 介紹影片（唯一需要改程式的地方）

影片**不是放檔案就會出現播放鍵**，要填連結。位置在 `index.html` 裡標了 `▼▼▼` 的那一行：

```html
<div class="img-container ... about-media" data-video="">
```

在引號中間貼上連結：

- **YouTube**：`https://youtu.be/影片ID`（分享網址後面的 `?si=...` 是追蹤碼，可以不要）
- **自己的影片檔**：放進 `images/` 再寫 `images/intro.mp4`
- **留空**：播放鍵自動隱藏，不會出現點下去沒反應的按鈕

三件要注意：

1. 畫面上那句「觀看 90 秒介紹影片」是寫死的文字，影片長度變了要一起改（就在 `data-video` 下面幾行）。
2. **用檔案直接開（`file://`）時，YouTube 會拒絕嵌入並顯示「錯誤 153」**——那是瀏覽器的來源限制，
   不是設定錯誤。程式已針對這種情況改成另開 YouTube 分頁。
3. 想在本機看到真正的頁內播放：在專案資料夾執行 `python -m http.server 8000`，
   再開 `http://localhost:8000`。

## 📐 通用原則

| 項目 | 建議 |
|---|---|
| 格式 | `.jpg`（照片）。需要透明背景才用 `.png`，但檔名的副檔名要跟著改，程式才找得到 |
| 檔案大小 | 每張 **400 KB 以內**。目前範例圖是 26–44 KB |
| 色彩 | sRGB。手機直出通常沒問題；從專業軟體匯出請確認不是 Adobe RGB，否則顏色會偏 |
| 檔名 | **不要改**。程式是照檔名找圖的，改了就會變成佔位框 |
| 大小寫 | GitHub 有分大小寫。`Hero-01.jpg` 與 `hero-01.jpg` 是不同檔案 |
| 直向照片 | 只有設計師頭像是正方。其他位置都是橫向（16:9、4:3、3:2）或正方，直向照片會被裁掉上下 |

## 🔄 換好之後怎麼生效

**本機看**：直接雙擊 `index.html`，或按 F5 重新整理。
看不到新圖時按 `Ctrl + F5`（強制重新整理，跳過瀏覽器快取）。

**放上網站**：把 `images/` 裡改動的檔案上傳到 GitHub。
換圖片建議用 **GitHub Desktop**（一次換好幾張比較方便），
逐步做法寫在上一層的 [../README.md 的「🚀 更新網站」章節](../README.md#-更新網站自己改完之後怎麼上線)——
從安裝、按哪顆按鈕、到改壞了怎麼還原都有寫。

上傳後 GitHub Pages 通常一到兩分鐘生效，網址是 `https://ziqing-hub.github.io/PaintingChair/`。

推上去了但還是舊圖，八成是瀏覽器快取——`Ctrl + F5`，或用無痕視窗確認。

## ❓ 常見問題

**Q：我只有幾張照片，可以先放一部分嗎？**
可以。每個位置都是獨立的，沒放的就顯示佔位框，不影響其他地方。

**Q：照片比例跟建議不一樣可以嗎？**
可以，程式會自動裁切（`cover`）或完整縮放（`contain`）。但比例差太多會裁掉重要內容，
建議先照建議比例裁好。唯一嚴格的是**同場景的原色／淡色兩張必須同角度**。

**Q：我想加第四張首頁主視覺？**
這需要改 `index.html`：每一張是一組 `.hero-slide`（含主圖、淡色圖、佔位框、色調滑桿），
下方的圓點區 `.hero-dots` 也要跟著加一顆。複製現有的一組再改檔名最快，
但循環輪播的複製格數與圓點數量是連動的，改完要確認三種寬度都正常。

**Q：`範例圖 SAMPLE` 角標怎麼拿掉？**
那個角標是烙在範例圖檔裡的，換成你的照片就沒有了，不用改程式。
